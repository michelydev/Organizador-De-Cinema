# Organizador de Maratona de Filmes

Projeto desenvolvido em **C#** para praticar conceitos fundamentais de lógica de programação por meio de uma aplicação executada no console.

O programa permite cadastrar as durações dos filmes e informar o horário de início da maratona. Com esses dados, ele calcula a duração total, a média das durações e o horário previsto para o término.

## Funcionalidades

- Definição da quantidade de filmes
- Cadastro da duração de cada filme
- Validação dos valores informados
- Cálculo da duração total da maratona
- Cálculo da duração média dos filmes
- Definição do horário de início
- Cálculo do horário previsto para o término

## Conceitos utilizados

- Entrada e saída de dados
- Variáveis e conversão de valores
- Estruturas condicionais
- Laços de repetição
- Vetores
- Métodos
- Operadores matemáticos e lógicos
- Estrutura `switch`

## Tecnologias utilizadas

- C#
- .NET
- Aplicação de console

## Como executar

1. Clone este repositório:

```bash
git clone URL-DO-REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd NOME-DO-REPOSITORIO
```

3. Execute o programa:

```bash
dotnet run
```

Também é possível abrir o projeto no **Visual Studio** e executá-lo pressionando `Ctrl + F5`.
